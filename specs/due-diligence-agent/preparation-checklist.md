## 4. 检索模型的准备方式

首轮候选：

- [Qwen3-Embedding-0.6B](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B)：本地向量化。
- [Qwen3-Reranker-0.6B](https://huggingface.co/Qwen/Qwen3-Reranker-0.6B)：本地重排序。

模型下载包含权重、分词器和配置；下载后进行本地推理，不是重新训练。采用经验证的标准推理方式，不将需要特定 GPU 的加速组件作为必装项。

已有 GTX 1070 不能仅凭显存大小认定兼容所有当前软件。先以 CPU、小批次完成正确性检查，再独立验证 GPU 后端、精度和速度；不预先要求购买新显卡，也不保证现有设备能高速处理全部 GB 级材料。

文档切片由应用规则完成，Embedding 负责将文本变成向量，Reranker 通常在检索阶段处理候选结果。三个环节可分别调试。模型版本或维度改变后须重建相应索引，不混合使用旧向量。

这些是拟定配置项，不是当前已经实现的接口或已创建的配置文件；真实密钥不要写入本文档或聊天。

| 类别 | 需要保存的配置 | 建议初始方式 |
| --- | --- | --- |
| 存储 | 原件、解析产物、模型缓存、报告、备份目录 | 优先 D 盘；客户端材料目录不进入代码仓库 |

| 推理参数 | CPU／GPU、批量大小、输入长度上限及向量维度 | 从小批次、兼容参数开始；不照抄高端显卡配置 |
| 外部模型 | 接口地址、模型名称、API Key、超时与预算 | 初始禁用；凭证保存在本地受保护配置中 |

| 法源 | 法域、来源、有效期间、更新及核验记录 | 从明确的试点范围开始 |
| 运行记录 | 日志位置、保留期限、必要错误与调用元数据 | 默认不复制完整原文或密钥 |

## 7. 建议准备顺序与完成检查

1. **项目环境：** 复用或更新兼容的稳定 Python，建立独立环境，不改默认预览版和其他软件。
2. **数据库：** 确认可复用实例；没有时建立本地 PostgreSQL 和 pgvector，配置持久存储与备份。
3. **最小应用依赖：** 准备应用框架、LangGraph 持久化、基础文件读取和 Word 输出。
4. **本地检索：** 下载小规格 Embedding、Reranker，完成中文向量化、写库、搜索及重排序测试。
5. **复杂文档处理：** 分别配置 Docling 和 PaddleOCR；必要时使用不同的隔离环境，避免强行混合冲突依赖。
6. **生成与业务验证：** 接入获准模型、模板和法源，验证完整章节；无外发许可且无本地生成模型时，明确停留在本地处理验证阶段。
7. **增大样本：** 记录质量、吞吐、内存和费用，再决定是否增加 GPU、服务器或容器部署。

环境就绪检查应包含：数据库重启后的数据保留、向量维度一致、OCR 来源定位、断网后的本地模型运行、流程恢复、Word 可打开，以及禁用外发时无材料发送。通过安装不等于通过这些检查。
