## c2 首批：显式查询与父块聚合

新增 `ParentSearch(evidence,index)`，作为可测试的显式内部调用入口，默认页级搜索仍不切换。要求数据库／模型实例一致，索引版本由 ParentIndex 生成，避免用旧页级分块版本查新表。纯模型输出复用现有缓存；交互请求共享原查询总预算、取消和模型资源调度。

数据流：查询向量 → 最多 12 个当前子块 → 仅对子块重排 → 同一只读快照内复验 build 谱系／全部来源依赖并读取父块 → 按父块聚合 → 最多 5 个结果。每组以最佳子块的重排分数、相似度和稳定身份排序；保留其他命中子块，不将上下文额外评分。最终子块文本／归属／spans 必须与模型评分输入相同，才采用该分数。内部最多 12×4000 字符父块正文，输出最多 5×4000，仍不加载整卷。

响应明确 `index_kind=parent_child`、`matched_children` 和 `context`；父块 spans 与子块 spans 保留原始坐标／source_revision，并新增逐页阅读导航链接。该链接是导航，不替代后续版本绑定的 HTTP 引用读取契约。覆盖当前返回 `complete=false,status=not_evaluated`，避免候选命中冒充完整材料覆盖。c1 的混合索引策略及 c3／c4 接线继续待做。

## c3：HTTP 版本引用与有界续读

新增 parent_references.py 和 app.py 的 GET 父块补读路由，具体契约见 plan.md。ParentSearch 结果附带 reference={url,params}，绑定 project／document／build／parent 和 index_version。补读不加载模型，身份存在性与来源／origin 有效性在同一 REPEATABLE READ 快照内判定。offset／limit 服务层与 HTTP 层均限制，续读保留所有身份与索引版本，最多返回 4000 字符，不静默跳转新原文。

404：不存在／跨项目统一提示；409 stale_reference：项目内引用来源／谱系或请求版本失效；422：缺版本、格式或预算无效。返回 source_spans 对应完整父块，derived 坐标不因切片重置；offset 明确本次文字位置。snapshot=version_pinned 表示绑定不可变 build 及当前有效源修订，不表示强制读取最新配置生成的索引。旧页级接口保留。
