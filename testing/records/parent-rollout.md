日期：2026-11-01。本子步实现后台配置接线及中文进度，不开启客户整卷，不切换搜索，也不表示整个 RG-06b 已完成。

## 使用与回退

默认 `DDA_PARENT_INDEX_MODE=off`。需要试运行时，在 `.env` 配置 `DDA_PARENT_INDEX_MODE=shadow` 和 `DDA_PARENT_INDEX_DOCUMENT_IDS=<材料UUID>`，多个 UUID 用逗号分隔，最多 20 个，不支持通配符或空名单，重复／无效 UUID、未知模式在启动时拒绝。材料 UUID 是阅读页面地址中 `document=` 后的值，也可从材料 API 的 `document_id` 获取。

先暂停正在运行的任务并等待安全保存，再正常停止／重启服务让配置生效，然后对指定材料启动或显式继续。配置本身不入队、不主动扫描或重建其他材料；CLI 小批 `run` 不走该后台开关。

回退设置 `DDA_PARENT_INDEX_MODE=off`（也可移出名单，但 shadow 名单不能全部为空），按上述步骤重启。新窗口和自动修复不再生成；已保存 tail／receipt／向量保留。同代次既有包沿用原消费者安全排空；重启、失去执行者及显式继续仍按原代次规则取消旧领取，再开启后按收据重新登记，不把旧 owner 复活。当前搜索始终使用原页级索引。off 不会强行中断正在执行的一次模型调用，算力暂停沿用现有暂停按钮。

只修改 `.env.example`，未改本机 `.env`。无新依赖、无新增迁移，仍使用 schema 015。

回退期间若来源或识别策略发生变化，再启用仍须复验来源。未封口旧尾段暂不支持局部替换，会保留成果并报告部分完成；已封口且兼容的基线可走既有局部修复。此次恢复通过针对来源未变场景，不保证所有变化都能自动恢复，也不通过整卷 reset 绕过保护。

## 接线与展示

`ProcessingPipeline.assembly_for` 在调度器拿到具体 job 后判定名单；名单外不创建 ParentIndex／tokenizer，名单内创建共享 Database 和已有 EvidenceService.models 的 RepairingAssemblyIngestion。对象构造不 profile、不加载模型；重计算继续走既有有界调度和模型许可。内部显式驱动注入保持兼容。

快照增加该材料实际 `parent_index_mode`。阅读页在原 aria-live 状态区域展示试运行及当前页级查询口径；组装页数、页级向量数、工作包数仍分开。局部重建显示来源核对、创建计划、定位窗口、重算、校验、接纳、完成或停止，以及已核对页数、计划次数和安全中文原因。接纳完成仍提示等待包与覆盖确认，不把接纳冒充全部索引完成。
