# RG-06c c4a 材料级覆盖资格

日期：2026-11-03。只读资格服务，尚不切换活动查询。

ParentCoverage.inspect(project,document,index_version) 在一个 REPEATABLE READ 快照中检查：

- 当前检查点的版本／归属／校验和、封口、末页和空尾段。
- 当前谱系中非 reset 收据的 input_dependencies 和 parents 元数据存在。
- 逐页依赖属于当前项目／材料，readiness=ready，当前有效页成功且源修订／质量相同；去重页数必须等于已知总页数，范围不能越界。
- 每个收据父块均存在该收据的交接来源、匹配版本／当前来源的已发布 build 与 parent。不是用向量总数或 job 内存计数估算完成。

输出仅为单材料的固定计数与 eligible/reason；无整卷正文返回，无模型或 tokenizer 调用，无任务领取／写入。空白就绪页可零父块完成；只有尾段、尚未发布、过期来源、元数据缺失、错误版本、损坏检查点、reset 和越项目均不得取得资格。返回 eligible 不表示识别准确率或法律事实已核实。
